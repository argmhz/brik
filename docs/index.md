# Brik

Brik er en 2D game engine til web. Du bygger scener i editoren, skriver gameplay i TypeScript og eksporterer spillet som en statisk mappe, der kan lægges på itch.io, GitHub Pages eller en hvilken som helst webserver.

Brug **Manualen**, når du skal slå noget op, **Guiderne**, når du vil lære det trin for trin, og **Roadmappet**, når du vil vide, hvad der er lavet, og hvad der kommer.
